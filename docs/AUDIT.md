# 仓库审查（2026-10-09）

本文记录工程审查发现的问题及修复状态，供源码维护与复核使用。

检查范围包括 Python、Vue、TS、CSS、配置、启动脚本、文档及依赖锁文件。当前源码中没有嵌套 `rag_qa_system/`，无需删除重复目录。用户运行数据不属于公开审查内容。

| 审查问题 | 当前处理 |
|---|---|
| 索引先删除再生成 | 新快照完整构建后原子切换指针 |
| 上传无限读取、原文件覆盖、无类型和大小校验 | 安全名称、20 MiB 限制、解析校验、失败回滚 |
| 原始异常暴露到 API 与界面 | 固定安全错误消息，不返回提供方响应体 |
| 连接测试会激活配置 | 指定配置测试，无切换副作用 |
| 语义模型隐式下载且无版本检测 | CPU、本地缓存加载、索引指纹 |
| DOCX 表格顺序丢失、切块跨 PDF 页 | 按文档顺序解析，先分页面和标题再递归切分 |
| 只有平面历史 | 独立会话和消息数据库，旧历史表保持可读 |
| 排名分数称为回答置信度 | 保留兼容字段，前端标签改为检索等级并注明非正确概率 |
| 空评测标注被记为全对 | 未标注返回 null，补充可核验测试资料 |
| App.vue 单体，V2 聊天界面不足 | 尚待拆分；多会话、Markdown、独立概览页面未完成 |
| 相对数据路径和全局环境 | 数据根路径固定，项目虚拟环境与统一启动脚本 |

修改范围：`main.py`、`modules/`、`app.py`、`eval_rag.py`、依赖、启动脚本、环境示例与 README；前端仍以 `App.vue` 为主。新增 `tests/`、`examples/corpus/`、发布打包脚本、审查与验证报告。验证结论以 [VALIDATION.md](VALIDATION.md) 为准，修复方向不代表所有规划均已完成。

兼容策略：保留既有路由，`DELETE /sources/{name}` 仍只删索引；旧 SQLite 历史表与模型配置格式不变；V1 的 `rag_documents` 视为原 Hash 索引，首次成功修改才创建活动快照指针；保留旧快照。仅支持本机、单进程、单用户运行。
